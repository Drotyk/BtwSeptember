# Telegram-бот для BTW September

Бот послідовно збирає дані анкети учасника BEST Training Week: ПІ, український номер телефону, Telegram username, навчальний заклад, курс, обрані тренінги, джерело інформації та дві згоди. Дані зберігаються у PostgreSQL.

Стек: TypeScript, Node.js, grammY та PostgreSQL.

## Швидкий запуск через Docker

1. Створіть бота через [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Створіть локальний `.env` на основі `.env.example` та вставте токен:

   ```bash
   cp .env.example .env
   ```

3. Запустіть PostgreSQL і бота:

   ```bash
   docker compose up --build
   ```

Міграції бази даних застосовуються автоматично перед стартом бота. Дані зберігаються в volume `postgres-data`.

Веб-інтерфейс для перегляду даних доступний за адресою:

```text
http://localhost:3000
```

Він працює тільки в режимі читання та підтримує пошук за ПІ, номером телефону, Telegram username або ID, навчальним закладом, курсом, джерелом інформації та тренінгами. Для кожної анкети відображаються обидві згоди окремо. За замовчуванням інтерфейс доступний лише локально.

## Локальний запуск без Docker

Потрібні Node.js 20+ і запущений PostgreSQL.

```bash
npm install
cp .env.example .env
npm run build
npm run migrate:up
npm start
```

Для локального запуску в `DATABASE_URL` використовується хост `localhost`. Значення `DATABASE_URL` з Docker Compose використовує хост `postgres`, тому воно призначене для контейнера бота.

Щоб запустити TypeScript-бот локально, але використовувати PostgreSQL із Docker:

```bash
docker compose up -d postgres
npm run build
npm start
```

У цьому режимі `DATABASE_URL` має використовувати порт `55433`. Порт `5432` або `5433` може бути зайнятий локальним PostgreSQL чи іншим Docker-проєктом.

Хост і порт веб-інтерфейсу можна змінити через змінні `WEB_HOST` та `WEB_PORT`. Не відкривайте його у зовнішню мережу без авторизації.

Підтримувані команди: `/start` — почати або перезаповнити анкету, `/back` — повернутися до попереднього кроку, `/cancel` — скасувати поточний ввід. На кроках анкети також доступна кнопка «⬅️ Назад».

Файли міграцій знаходяться в директорії `migrations/`. Застосувати незапущені міграції вручну можна командою `npm run migrate:up`.
